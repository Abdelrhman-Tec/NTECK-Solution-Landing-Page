# 02 — Repository audit and architecture
Read `01_GLOBAL_RULES.md` first.

## Tasks
1. Inspect repository, package manager, versions, existing code, git status, assets, and scripts. Never overwrite blindly.
2. Determine compatibility of Next.js App Router, Tailwind v4, shadcn/ui, Motion, React Hook Form, Zod, next-intl. Use compatible current versions; do not guess API signatures.
3. Draft concise architecture and dependency plan in `docs/architecture.md` with routing, server/client boundaries, translation organization, form submission, booking, configuration, and hosting constraints.
4. Create/adjust an implementation checklist in `docs/implementation-checklist.md` covering phases 03–12.
5. Identify missing assets/configuration in `docs/pending-configuration.md`: original logo variants, actual approved case studies, Facebook, WhatsApp, email, Google appointment booking URL, active payment methods, legal/business details.
6. Confirm no fake credentials or paid subscriptions will be required.

## Deliverables
Audited repository, architecture doc, phase checklist, pending configuration list. Fix any blocking foundation issues that prevent phase 03. Run available baseline checks and report actual results.
