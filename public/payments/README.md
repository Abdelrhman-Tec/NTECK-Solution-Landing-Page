# Payment marks

Add only approved, legally usable marks supplied by the provider or owner. Put each under this directory and record its intrinsic dimensions in `src/config/payments.ts`. Enable a method only after the owner verifies it is active. Visa and Mastercard also require `liveCardProcessorVerified: true` after checking the live merchant processor. Verify cross-border payment options with the owner before offering them to clients. Keep the artwork and aspect ratio intact.
