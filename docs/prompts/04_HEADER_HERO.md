# 04 — Navigation and conversion-focused Hero
Read `01_GLOBAL_RULES.md` first. Implement the Header and Hero on both locales.

## Header
Sticky premium dark navigation with original logo, Home, Services, Work, Process, Book a Meeting, Contact, locale switcher. Mobile accessible menu: keyboard, focus, Escape, closes after navigation, RTL/LTR positioning. CTA routes to real booking section, not an inert button. Header gains subtle translucent background on scroll without jank.

## Visual direction
Premium dark-purple gradient, soft glow, original lightweight CSS/SVG product interface composition (mobile app, dashboard, development pipeline), **no fake customer brands or metrics**. Strong hierarchy and negative space, elegant hover, restrained Motion animations with reduced-motion support. Optimize LCP; no heavy autoplay video.

## Acceptance
Both locales look polished at 360px, 768px, and desktop; primary and secondary CTAs work; logo correct; no horizontal overflow; keyboard accessible.
